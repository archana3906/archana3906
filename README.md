### 🔐 TrustOTA
**Behavioral Verification for Automotive Software Updates**

CARLA-based digital twin scenarios (emergency braking, obstacle avoidance, lane keeping, normal driving) check how an OTA update changes vehicle behavior. A React dashboard shows ACCEPT/REJECT decisions and drives an STM32 Nucleo-F446RE + LCD over UART.

🎯 Rejected an update that passed all four security checks after detecting **16.6% stopping-distance** and **21.0% braking-time** regression against a 10% safety threshold.
📄 Co-authored research paper (manuscript under revision).
